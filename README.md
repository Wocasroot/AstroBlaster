# AstroBlaster

A simple 80s-style arcade shooter. Use **Arrow Keys** to move and **Spacebar** to shoot on desktop.

## Play on phone (Apple iPhone / Android)
This game now includes on-screen touch controls for mobile:
- **◀ / ▶** turn your ship
- **▲** thrust
- **●** fire

Open this HTML file directly to play:
- `AstroV14.HTML`

If hosted on GitHub Pages, your play link will be:
- `https://<your-username>.github.io/AstroBlaster/AstroV14.HTML`

## Play locally (desktop or mobile browser)
1. Download this project as a ZIP (or clone it).
2. Extract the ZIP.
3. Open `AstroV14.HTML` in your browser.

## Upload this project to your GitHub
If you already created an empty repo on GitHub (for example `https://github.com/<your-username>/AstroBlaster`), run these commands from this folder:

```bash
git branch -M main
git remote add origin https://github.com/<your-username>/AstroBlaster.git
git push -u origin main
```

If `origin` already exists, update it instead:

```bash
git remote set-url origin https://github.com/<your-username>/AstroBlaster.git
git push -u origin main
```

## Direct download link (after upload)
After pushing to GitHub, your game ZIP link will be:

`https://github.com/<your-username>/AstroBlaster/archive/refs/heads/main.zip`

Replace `<your-username>` with your actual GitHub username.
